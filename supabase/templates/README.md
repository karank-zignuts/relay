# Auth email templates

Generated by `npm run emails:build` from `scripts/build-email-templates.mjs`. Edit the script, not the HTML.

Paste each file into **Supabase → Authentication → Emails → Templates** and use the subject shown.

| Template in Supabase | File | Subject |
|---|---|---|
| Invite user | `invite.html` | You're invited to Relay |
| Reset password | `recovery.html` | Reset your Relay password |
| Confirm sign up | `confirmation.html` | Confirm your Relay email |
| Magic link | `magic_link.html` | Your Relay sign-in link |
| Change email address | `email_change.html` | Confirm your new Relay email |
| Reauthentication | `reauthentication.html` | Your Relay confirmation code |

Invite and reset links go to `{{ .SiteURL }}/set-password?token_hash=…`, so **Site URL** in Authentication → URL Configuration must be your app's URL. Relay never uses sign-up confirmation or magic links (sign-up is off), but they are styled so every email matches.
